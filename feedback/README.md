# Feedback

- `log.jsonl`: one critique per line, written by `skills/deck/scripts/feedback.py` (user, reviewer or scorecard).
- `proposals.md`: recurring critiques grouped by `curate_feedback.py`, for the user to validate.
- `changelog.md`: what the curator changed, with the commit.

Critiques are patterns: no client name, no figure, no sentence copied from a deck.
